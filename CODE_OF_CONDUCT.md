# Community expectations

Be welcoming, respectful, and specific. Critique technical work without attacking people. Harassment, discrimination, threats, doxxing, spam, and posting credentials or private user content are not acceptable.

Maintainers may edit or remove harmful content, close discussions, and restrict participation when needed. Keep enforcement proportional and explain decisions where doing so does not expose private information.

For a private conduct concern, contact the maintainer through an available private channel on their linked public profile. If none is available, open an issue asking for a private contact without naming affected people or disclosing details. Security vulnerabilities have a separate route in SECURITY.md.
