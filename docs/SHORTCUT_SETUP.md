# Capture setup

The default shortcut is Control–Option–X. Open Settings → Basics to record a different combination. Snipstep registers a global shortcut while the app runs; closing the window does not quit the app. A conflicting shortcut is reported rather than stealing another registration.

Grant Snipstep screen recording permission in macOS when requested, then retry. The shortcut captures the full display under the pointer, with no selection drag. The sound plays after local save; enrichment continues separately. Screen access is unnecessary for manual tasks.

An optional Apple Shortcuts action, internally named Save Screenshot to Snipstep, accepts a screenshot image. Connect Take Screenshot to that action; do not substitute a generic Save File action. The scripts/make-shortcut.py development helper can generate a workflow for your own signing team. Generated signed shortcut files are excluded from Git.

Use a stable signed app for widget/permission verification. Avoid launching several build copies with the same bundle ID. A stale macOS widget gallery icon may outlive an app update; do not delete a library or reset privacy grants to fix artwork.
