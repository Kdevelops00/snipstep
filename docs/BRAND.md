# Snipstep identity

**Snipstep — screenshots with a next step.**

A screenshot usually means “I want to come back to this.” Snipstep turns that intention into a task, keeps the original close, and makes it visible on the desktop. Ordinary typed tasks belong here too.

The name joins a captured moment (“snip”) to action (“step”). It is shorter and more distinctive than ScreenToDo, and more concrete than StillCue. Initial web searches found no matching software product; that is not trademark clearance.

The blue capture-bracket S mark represents keeping a frame and moving forward. Keep the glass interface restrained: readable text, clear controls and brief completion feedback, with no decorative playback controls.

Creator and maintainer: [@Kdevelops00](https://github.com/Kdevelops00). Public claims must match working behavior. See CREDITS.md for upstream technology and assistance.

The application, app menu and widget names use Snipstep. Internal SnapLater storage paths, bundle IDs and URL links preserve existing libraries and credentials.
