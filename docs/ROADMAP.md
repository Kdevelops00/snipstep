# Snipstep roadmap

This is direction, not a delivery promise. Proposals should preserve a simple to-do list.

## Developer preview

- Manual tasks and widget-to-composer entry
- Screenshot context, offline OCR, and editable notes
- Optional LLM API summaries with user keys or a supported local model
- Native To-Do/Progress widgets and local Analytics
- Source, tests, privacy documentation, and a product walkthrough

## Before a consumer download

- Verify a clean contributor setup and stable signing workflow
- Complete accessibility, minimum macOS, Intel, and multiple-display testing
- Exercise real disk failures, permission transitions, and long-lived libraries
- Validate widget completion, composer focus, and deletion across app launch states
- Prepare Developer ID distribution, notarization, and update strategy
- Review consumer distribution requirements for optional providers

## Explore with the community

- Export and backup workflows
- Better nontechnical model setup
- iPhone capture and optional sync, only after a clear privacy design

No account system, telemetry, social feed, or mandatory cloud dependency is planned for the basic task workflow.
